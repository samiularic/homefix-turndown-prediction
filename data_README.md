# Data

The HomeFix data files are not included in this repository for confidentiality reasons. They were provided by HomeFix Custom Remodeling for the Experiential Analytics Challenge competition only.

## Required files (not included)

To run the analysis, place these files in this folder:

- `PureFinanceApplications.xlsx` — 3,397 finance applications
- `Pure Soft Pull Runs.xlsx` — 81,922 soft pull credit runs
- `income.xlsx` — ZIP-level median income from US Census ACS (publicly available)
- `zillow.xlsx` — ZIP-level home values from Zillow ZHVI (publicly available)

## Public data sources

The external data used in this project is publicly available:

- US Census ACS 5-Year Income by ZIP: https://data.census.gov
- Zillow Home Value Index: https://www.zillow.com/research/data/
